# 🎬 AI Shorts Factory

Automatiza la creación de shorts con IA:
- 🧠 Guion: OpenAI GPT-4o
- 🎙️ Voz: ElevenLabs
- 🎥 Video: RunwayML
- ✂️ Edición: CapCut
- ⚙️ Automatización: Python
- 📊 Gestión: Notion

## Requisitos
- Python 3.10+
- Claves de API de OpenAI, ElevenLabs y Notion

## Instalación
\`\`\`bash
pip install -r requirements.txt
\`\`\`

## Ejecución
\`\`\`bash
python scripts/runner.py
\`\`\`
