## 🏗️ 1. Arquitectura General

**IOPeer** es una plataforma tipo **n8n / Activepieces**, pero con enfoque en **automatización inteligente mediante agentes y pipelines**.  
Está construida como un **monorepo pnpm** con varios `apps` y `packages`.

### Estructura principal
```
iopeer/
├─ apps/
│  ├─ api/           # Backend NestJS + Prisma + Supabase
│  ├─ web/           # Frontend (Next.js / React)
│  └─ worker/        # (planeado) ejecución de jobs / scheduler distribuido
├─ packages/
│  ├─ shared/        # Tipos, utils, constantes
│  ├─ agents/        # (planeado) agentes IA y workflows automáticos
│  └─ scripts/       # DevOps / build helpers
```
