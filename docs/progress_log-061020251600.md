## 🤖 3. Sistema de reportes inteligentes (nuevo módulo)

Estructura modular creada:

```
reports/
 ├─ report.service.ts
 ├─ report.scheduler.ts
 ├─ slack-notifier.ts
 ├─ email-notifier.ts
 ├─ report.controller.ts
 ├─ report.module.ts
 └─ beautifier/
     ├─ beautifier.types.ts
     ├─ beautifier.strategy.ts
     ├─ beautifier.ollama.service.ts
     ├─ beautifier.hf.service.ts
     └─ beautifier.groq.service.ts
```

Cada servicio conecta con un proveedor IA distinto (Ollama local, HuggingFace, Groq), gestionados por un **orquestador con fallback** inteligente.
