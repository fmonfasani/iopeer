## 🧪 Criterios de aceptación
- `/runs` → crea y devuelve id.
- `/runs/:id` → estados PENDING/SUCCESS/ERROR.
- `/health` → 200 + DB OK.
- `/metrics` → p95, error_rate.
- Logs correlacionados por requestId.
- Coverage ≥ 70%.
- CI verde + artifact coverage.
- Secretos cifrados y no expuestos.

---

## ⚠️ Riesgos y mitigaciones
- **Fugas de secretos** → secret scanning + rotación.
- **Retries infinitos** → límite y jitter.
- **Bloqueos** → watchdog por duración.
- **Shell step** → whitelisting, flag desactivado.
- **Desfase API/UI** → SDK compartido + swagger mínimo.
